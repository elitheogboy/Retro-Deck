# Retro Deck for GitHub Pages

Static game catalog for a GitHub Pages project site. The catalog includes 481
game cards, individually downloadable ZIPs, and a signed Android APK.

Publish the contents of this folder to a GitHub repository's main branch.
In the repository, open Settings → Pages, choose Deploy from a branch, and
select main and / (root). Use a repository and Pages visibility suitable
for the files you want to share.

All web paths are relative so the catalog works under a repository URL prefix.
The APK has the same package ID and signing certificate as prior Retro Deck
builds. Use the website for catalog browsing and import downloaded games
using the app's Import games button.
